# 小智 · 微雪 ESP32-S3 RLCD 4.2 功能说明

一块 400×300 单色反射屏的桌面小站：语音对话、网易云点歌、自定义壁纸、备忘录、提醒。

> 本文只讲**怎么用**。编译环境、技术取舍、踩坑记录、排障方法见 **`开发文档.md`**。

---

## 一、硬件与环境

| 项目 | 规格 |
|---|---|
| 主控 | ESP32-S3（双核 240 MHz） |
| 屏幕 | 400×300 反射式单色 RLCD（SPI） |
| 内存 | 8 MB Octal PSRAM（80 MHz）+ 512 KB 内部 SRAM |
| Flash | 16 MB |
| 音频 | ES8311（输出）+ ES7210（4 麦输入），24 kHz 单声道输出 |
| 存储 | NVS（壁纸常驻，分区已扩到 64 KB） |
| 固件框架 | ESP-IDF v5.5.5 + LVGL |

---

## 二、编译与烧录

```bash
# 编译
cd E:\esp32test\waveshare-rlcd-v2
idf.py build

# 烧录（默认 COM7，可在 flash.bat 里改）
flash.bat
```

首次在新机器上编译需要先 `idf.py reconfigure`，组件管理器会按 `dependencies.lock` 自动拉取依赖。

> 编译报错、卡住、改配置后的注意事项，见 `开发文档.md` 第一章。

## 三、三大页面

三页共用「黑底 + 白色圆角卡」的视觉语言，但顶栏不同：

- **主页**：黑底白字状态栏（温湿度 + 图标），没有胶囊
- **备忘录 / 播放器**：顶部是 376×30 白色胶囊，左边时间、中间页面名、右边电量

> 三页共用一套**对话小卡**：说话时会自动盖在页面右下角显示最近对话，空闲立刻收回，
> 完全不影响页面本身的布局。说「放大对话列表」才铺满全屏（详见第四章第 1 节）。

### 1. 主页

```
┌────────────────────────────────────────────┐
│ 23.5°C 48%            [wifi][bat] 86%      │  状态栏
├──────────────────────┬─────────────────────┤
│                      │  11:42              │  时间卡
│   照片 214×252        │  11月17日 周一        │  158×102
│  （2px 白框，        ├─────────────────────┤
│    内图 210×248）     │  提醒 / 语音识别      │  双态卡
│                      │                      │  158×142
└──────────────────────┴─────────────────────┘
```

- **状态栏**：左边室内温湿度（传感器实时值），右边 WiFi 图标 + 电池图标 + 电量百分比
- **左侧照片位**：214×252，外圈 2px 白框，内部图像 210×248；没图时提示「把 JPG 放进 /sdcard/photos」
- **右上时间卡**：大号时间 + 日期 + 星期
- **右下双态卡**（同一块区域复用，随设备状态切换）：
  - **空闲** → 「提醒」列表，最多 3 条，第一条反白高亮
  - **语音时** → 「聆听中」胶囊 + 计时 + 你说的话（反白气泡）+ AI 回复

> ⚠️ 天气信息**当前不在主页显示**。改版成「照片 + 时间 + 提醒」三块后没有天气的位置了。
> 天气模块代码仍在，问「天气怎么样」时助手仍会回答。

### 2. 备忘录（提醒目录）

```
┌──────────────────────────────────────────────┐
│ ╭──────────────────────────────────────────╮ │  白色胶囊头
│ │ 18:07 ▂▃   备忘录           86% ▮▮      │ │
│ ╰──────────────────────────────────────────╯ │
│ ┌──────────────────────────────────────────┐ │
│ │▛▛ 和设计组过一遍 UI 稿        ▛12:07▛▛│ │  首条整车反白
│ │  回复微雪的技术邮件            15:40    │ │
│ │  给 RLCD 板子刷一版固件        18:20    │ │
│ │  每天 整理本周的排期           21:00    │ │
│ └──────────────────────────────────────────┘ │
│ 共 4 项待办                          01│03   │  页脚
└──────────────────────────────────────────────┘
```

- 本质是**提醒/闹钟目录**（数据源 `ReminderManager`），不是普通待办清单
- 每行：左侧内容 + 右侧时间（24px 大号数字）
- **首条整车反白** = 下一条要响的那条
- 每日重复的条目响过后会自动滚到下一个周期，不会消失
- 单次提醒响过即从列表移除，所以不会出现「响过的闹钟还挂着」
- 超过一屏时有页脚页码（`01│03`），可语音翻页


### 3. 音乐播放器

```
┌──────────────────────────────────┐
│ 18:07 ▂▃     播放器       86% ▮▮ │  白色胶囊头
│ ┌──────────────────────────────┐ │
│ │   ●●●●●●●   夜航 Nocturne    │ │  曲名 20px
│ │  ●  (小智) ●  LUMEN FIELD    │ │  歌手 16px
│ │   ● ◜◝◟◞ ●   ──────────      │ │  分隔线
│ │    ●●●●●●●   当前句歌词（反白）│ │  当前句反白
│ │              下一句歌词        │ │  上一句/下一句淡显
│ └──────────────────────────────┘ │
│      |◀      ( ❚❚ )      ▶|      │  控制区
│  ━━━━━━━━●───────────────        │  进度条
│  01:24                    04:32  │
└──────────────────────────────────┘
```

- **唱片外围旋转**（每 300ms 一圈的一点），中心固定显示**小智 AI 头像图标**
- **歌词三行**：上一句 / 当前句（反白）/ 下一句，整句切换时向上滚动 180ms
- **进度条** + 已播 / 总时长
- ⚠️ 屏幕没有触摸，底部的 `|◀ (❚❚) ▶|` **只是状态指示，不能点**，播放控制全部靠语音或控制台
- 唱片中心不放专辑封面（1-bit 屏显示不了彩色图，已改用头像图标）

## 四、功能清单

### 1. 语音对话

- 唤醒词：**你好小智**
- 链路：麦克风 → ASR → LLM → TTS（走小智官方服务）
- 情绪表现：以文字体现（聆听中 / 思考中 / 说话中 / 待命）
- ⚠️ 系统只有语音链路，**没有文字输入通道**，无法做打字对话

#### 对话记录：小卡 + 全屏两层

| 层 | 触发 | 内容 |
|---|---|---|
| **小卡**（常驻） | 连接中 / 聆听中 / 回答中自动出现，空闲立刻收回 | 三页通用的白底小卡，显示最近 2 轮 |
| **全屏放大层** | 说「**放大对话列表**」 | 铺满一屏，显示最近 **3 轮**完整记录 |

- 放大层**不会自己冒出来**，必须明确开口才展开
- 说「**收起**」，或**空闲 12 秒**自动收回
- 小卡底部有提示：「说「放大对话列表」看完整记录」
- 同一条回复分多句下发时，按轮自动拼接，不会一句一条
- 工具类操作（放歌、翻目录、换图）那一轮不出卡，把结果页完整让出来


### 2. 网易云点歌

- 说"放一首晴天"或从控制台点歌
- 走 Java 控制台中转：搜索 → 取直链 → 取歌词
- 歌词 LRC 自动解析并同步滚动
- 支持暂停 / 继续 / 停止 / 音量调节

### 3. 自定义壁纸

**方式一（推荐）**：板子自己开的网页

```
浏览器打开 http://<板子IP>/
选图 → 上传
```

**方式二**：Java 控制台

```
http://localhost:8800 → 上传壁纸
```

特性：
- 图片自动裁成 **210×248**（屏幕原生尺寸，1:1 解码，画质最好）
- 写入 NVS，**断电重启后仍是这张**
- **断网也能显示**（不依赖网络）
- 上传失败自动重试 3 次

### 4. 备忘录 / 提醒

- 语音添加："提醒我十分钟后喝水" / "记一下明天交材料"
- 到点屏幕弹出提醒，支持 snooze（稍后提醒）
- 列表超过一屏时可翻页
- 说"第一条完成"标记完成，"清空备忘录"全清

### 5. 页面切换

语音："打开备忘录" / "回到主页" / "打开音乐"

> 主页在代码里叫 weather 页（`SetupWeatherUI`），所以语音说"开天气"也会回到主页，
> 但主页上并没有天气信息展示。

> **说明**：截屏、OTA 升级、重启、音量控制等属于小智官方固件的通用能力
> （`main/mcp_server.cc` / `main/ota.cc`），不是本项目的定制内容，此处不展开。
>
> **关于 SD 卡**：照片轮播（`/sdcard/photos`）和本地音乐（`/sdcard/music`）的代码仍然保留，
> 但本机未插卡（每次开机报 `sdmmc_card_init failed 0x107`），实际用不了，故未列入功能清单。
> 插上卡后这两个功能即刻可用。

## 六、控制台（Java）

位置：`tools/xiaozhi-console`

### 环境要求

| 用途 | 需要装什么 |
|---|---|
| **只是运行**（推荐） | **Java 17+（JRE 就够）** |
| 想改代码重新编译 | 再装 Maven 3.9+ |

Java 下载：https://adoptium.net/temurin/releases/?version=17 （选 Windows x64 的 `.msi`）

### 直接运行（换电脑也能用）

压缩包里 `target/xiaozhi-console.jar` 已经是编译好的，**不用装 Maven**：

1. 装 Java 17 或更高版本
2. 解压 `小智RLCD_控制台.zip`
3. 双击 `xiaozhi-console\start.bat`

`start.bat` 会调用 `find-java.ps1` **扫描全系统**找 Java，按注册表 + 常见安装目录 + `PATH`
收集所有 java.exe，探测版本后取**最高且 ≥17** 的那个。

> ⚠️ 它**不会盲信 `JAVA_HOME`**。很多机器上 `JAVA_HOME` 指向 Java 8（别的软件装的），
> 而真正的新版 JDK 在 `C:\Program Files` 下。旧版脚本就是因为优先用 `JAVA_HOME`
> 才报 `UnsupportedClassVersionError`（class file version 61.0 / up to 52.0）。

**不需要手动配环境变量。**

启动后浏览器打开 **http://localhost:8800**（脚本会自动弹）。

### 从源码编译

```bash
cd tools\xiaozhi-console
mvn -DskipTests package
start.bat
```

### 换电脑打不开的排查顺序

| 现象 | 原因 | 处理 |
|---|---|---|
| `UnsupportedClassVersionError`（61.0 / 52.0） | 用了 Java 8 启动 | 用新版 `start.bat`（会自动跳过 Java 8）；或手动指定 `JAVA_HOME` 到 17 |
| 黑窗口一闪就没 | 没装 Java 17+ | 装 Java 17，脚本会给出下载地址 |
| 提示「找不到主程序」 | `target` 文件夹没解压出来 | 重新完整解压，`target` 要和 `start.bat` 同层 |
| 浏览器打不开 8800 | 端口被占用或启动失败 | 看黑窗口里的报错；关掉占用 8800 的程序 |
| 面板显示离线 | 电脑和板子不在同一网段 | 确认同一路由器；板子 IP 变了会自动重新发现 |

### 手动指定 Java（脚本找错时）

临时指定某个 Java 启动：

```bat
set JAVA_HOME=C:\Program Files\Java\jdk-17
start.bat
```

或直接跑：

```bat
"C:\Program Files\Java\jdk-17\bin\java.exe" -jar target\xiaozhi-console.jar
```
浏览器打开 **http://localhost:8800**，功能：

| 模块 | 作用 |
|---|---|
| 设备状态 | 在线状态、IP、当前页面、电量、内存 |
| 点歌 | 输入歌名 → 搜索 → 播放（含暂停/继续/停止） |
| 上传壁纸 | 选图 → 自动压缩 → 写入板子 NVS |
| 快捷命令 | 音量、切页、重启、状态查询 |
| 事件日志 | 实时看板子做了什么 |

板子发现用 UDP 8801 广播，控制台启动后自动找到设备。

## 七、串口命令

板子 USB 串口（115200）支持一套调试命令：

```
help                     列出所有命令
ip                       板子当前 IP
relay [host:port]        查看/设置音乐中转地址
play <关键词>             搜歌并播放
pause / resume / stop    暂停 / 继续 / 停止
volume [0-100]           查看/设置音量
page <home|weather|memo|music>   切页面
photo [reset|save]       查看/清除常驻壁纸
status                   一句话看当前状态
reboot                   重启
```

## 八、已知限制

1. **WiFi 信号弱时放歌会卡**：音乐流是持续下载，信号差必然断。建议板子离路由器近一些（RSSI 优于 -60）。
2. **翻唱版歌词可能对不上**：没配 cookie 时点歌容易拿到翻唱版，其 LRC 时间轴与原曲不同。
3. **1-bit 屏显示不了彩色封面**：专辑封面已移除，唱片中心改为小智 AI 头像图标。
4. **PSRAM 80 MHz 对供电敏感**：用电池供电时，电量低可能出现偶发解码失败，建议用 5V 适配器。
